## Goal of the project

- My goal is for [this project] is to make a tool that makes it easier to manage the daily aspects of my life either now or in the future while develop this development skill set. This means that **every feature** will be designed with my needs(which may not be understood to others) in mind.

## Contributing

- I do not intend nor do I want to support [this project] beyond what I actually need.
- Beware that contributions will rarely<sub>1</sub> be accepted and as such, you are advised to `fork` the repository or try contacting me if you really think that the suggestion might be applicable to me but try and get clarification before putting effort and time into any contribution.
- The following contributions have greater chances of being accepted:
  1. Security fixes
  2. Bug reports
- AI generated contributions or drop by contributions have lower chances of being accepted 

## Reporting

1. Security
  - Contact me using [this project]'s Github private vulnerability reporting.
2. Bug
  - Please open a `PR`
